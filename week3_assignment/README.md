# Week 3 — Object-Oriented Programming + Python Libraries

## Overview
This project contains the Week 3 Assignment, demonstrating various Python Object-Oriented Programming (OOP) concepts and the usage of Python standard libraries to create functional, beginner-friendly CLI applications.

## Learning Objectives
- Classes and Objects
- Constructors (`__init__`)
- Inheritance and Polymorphism
- Encapsulation and Data Validation
- Exception Handling
- Python Standard Libraries (`math`, `random`, `datetime`)
- Object Interaction
- Practical OOP Design

## Project Structure
- `bank_account.py`: Bank system with encapsulation.
- `library_system.py`: Library management simulator.
- `calculator.py`: Basic calculator with exception handling.
- `library_demo.py`: Standard library usage examples.
- `oop_concepts.py`: Inheritance and polymorphism examples.
- `billing_system/`: Mini-project for invoice generation.

## How to Run
Ensure you have Python 3.x installed. Navigate to the `week3_assignment` directory and run any of the files:
```bash
python bank_account.py
python library_system.py
python calculator.py
python library_demo.py
python oop_concepts.py
python billing_system/main.py
```

## Features
- Robust input validation and exception handling.
- Clean and readable CLI menus.
- Modular code structure.
